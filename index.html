Hello there. I'm Tom. I'm a software engineer, game developer, musician and finance enthusiast. I began writing code when I was 8 years old to build 2D games in Game Maker 6.0, then branched out to C#, Lua, Basic, Go, PHP, TypeScript and C++. In 2018 I founded an app development agency which shipped over 100 orders using Dart/Flutter. I've since worked on wearables (using BLE) and software for financial advisers, before studying and becoming a financial adviser to see how the industry functions.

As a long-time AI skeptic, I've recently embraced the use of AI in development, and it's allowed me to push my projects beyond what I thought was possible. This has, in turn, renewed my passion for software engineering and game development, and I'm excited to work on projects with fully hand-written code, AI-assisted code, and in some cases entirely vibe coded projects (it's fun!)
